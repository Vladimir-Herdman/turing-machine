# Turing Machine Simulator
This project is for an honors project requirement. Done in conjunction with
ECCS 4431 *Theory of Computation*.

Here's the link to the actual GitHub Pages website being statically hosted:
- [https://vladimir-herdman.github.io/turing-machine/](https://vladimir-herdman.github.io/turing-machine/)
## Local Setup
For your own local development, clone the repo and run some npm commands, as
below (requires, then, `node` and `npm` installed on your system):
```bash
npm i
npm run dev
```
This will locally run the site to a port on your computer (it'll print out
what port to open to in a browser).
